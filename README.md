# Active Directory Home Lab

## Overview

This project documents a Windows Active Directory home lab built to develop hands-on IT support and system administration skills.

## Environment

- Windows Server 2022
- Windows 10 Client
- Active Directory Domain Services (AD DS)
- DNS
- Group Policy
- VirtualBox

## Skills Practiced

### User Management
- Created user accounts
- Reset passwords
- Unlocked user accounts
- Managed user permissions

### Active Directory
- Installed and configured AD DS
- Joined Windows 10 client to the domain
- Managed users and security groups

### Group Policy
- Applied desktop wallpaper policy
- Configured password restrictions
- Updated policies using gpupdate

### Troubleshooting
- Account lockouts
- Login issues
- DNS configuration
- Domain connectivity
